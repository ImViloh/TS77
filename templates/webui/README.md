# __RESOURCE__

A React page hosted by OPEN//77's Chromium WebUI. The page is not Lua. Client Lua creates the surface and talks to it through `window.Open77`.

```bash
npm install
npm install --prefix ui
npm run dev
```

`npm run dev` starts Vite when `ui/node_modules` is installed. The dev URL is the player's computer when the page is opened in the game.
